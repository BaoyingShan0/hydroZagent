# hydroZagent Desktop

This is the Electron user interface of `hydroZagent`. It provides project and session management, the hydroZagent visual system, and LAN Web sharing.

The desktop app is developed and released together with the Agent runtime in `../../packages/coding-agent`. Use the commands in the [repository README](../../README.md); see the [product architecture](../../docs/product-architecture.md) for runtime and packaging boundaries.
